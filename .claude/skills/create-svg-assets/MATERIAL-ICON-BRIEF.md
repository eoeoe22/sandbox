# 물질 아이콘 SVG 발주서 (자체 완결 문서)

> **이 문서 하나로 충분하다.** 저장소를 열 필요도, 코드를 읽을 필요도, 다른 문서를
> 참조할 필요도 없다. 외부 도구·외부 환경·맥락이 끊긴 에이전트에게 이 파일만
> 통째로 건네면 된다. 여기 적히지 않은 값은 **추측하지 말고 발주자에게 묻는다.**

---

## 1. 무엇을 만드는가

브라우저에서 도는 **모래상자(falling-sand) 파티클 시뮬레이터**가 있다. 화면 대부분은
격자 캔버스이고, 사용자는 왼쪽 팔레트에서 "물질"을 골라 캔버스에 칠한다.

팔레트의 물질 하나하나에는 **18×18 CSS 픽셀짜리 작은 정사각 타일**이 붙는다. 그
타일이 이 발주의 대상이다. 물질 대부분은 게임이 실제로 그리는 질감(알갱이 스페클,
격자 직조, 화살표, 열 램프, 구름)을 자동으로 축소해서 쓰지만, **일부 물질은 게임
안에서도 그냥 단색 덩어리**라 축소할 질감이 없다. 그런 것들과, 자동 생성 결과가
어색한 소수를 **손으로 그린 SVG**로 대체한다.

**핵심 제약 두 가지를 먼저 머리에 넣을 것:**

1. **최종 표시 크기는 가로세로 18 CSS 픽셀이다.** 엄지손톱보다 작다. 세밀한 묘사는
   전부 뭉개진다. "작게 줄여도 알아볼 수 있는가"가 유일한 품질 기준이다.
2. **타일에는 빈 곳이 없어야 한다.** 배경이 비치면 안 된다(이유는 §3).

## 2. 파일 규격 (하드 스펙 — 어기면 반려)

| 항목 | 값 |
|---|---|
| 루트 | `<svg>` 하나. XML 선언(`<?xml …?>`)과 DOCTYPE **없이** |
| `viewBox` | `0 0 24 24` — **정사각 고정.** 즉 24×24 격자 위에 그린다 |
| 도형 | **`<rect>`만.** 다른 도형 요소 일절 금지 |
| 좌표·크기 | `x` `y` `width` `height` 모두 **0 이상의 정수**. `width`/`height`는 1 이상 |
| 색 | `fill="#rrggbb"` — 6자리 소문자 16진수. 이름 색·`rgb()`·8자리 금지 |
| 배경 | **첫 rect가 타일 전체를 덮어야 한다**: `<rect x="0" y="0" width="24" height="24" fill="#기본색"/>` |
| 투명 | **금지.** 576칸 전부 칠해진 상태여야 한다 |
| 개수 | rect **200개 이하**, 파일 **6 KB 이하** |
| 파일명 | 물질 영문명 kebab-case + `.svg` (예: `dry-ice.svg`, `solar-panel.svg`) |

### 절대 쓰지 말 것

`id` · `class` · `<defs>` · `<style>` · `<filter>` · `<mask>` · `<clipPath>` ·
`<use>` · `<image>` · `<text>` · `<g>` · `url(#…)` · `<linearGradient>` ·
`<radialGradient>` · `fill="none"` · `fill-opacity` · `opacity` · `stroke` 계열 ·
외부 파일/폰트/URL 참조 · CSS 변수

**이유(중요 — 취향이 아니라 기술적 제약이다):** 이 SVG는 파일로 로드되지 않는다.
마크업이 **HTML 문서 안에 그대로 인라인 삽입**되고, **같은 물질의 같은 마크업이 한
화면에 동시에 여러 벌 존재할 수 있다**(카테고리 목록 + 즐겨찾기 줄 + 검색 결과에
동시에 뜬다). 그래서:

- `id`와 `url(#…)`는 **자기 복제본과 이름이 충돌**한다. 그라디언트·마스크·필터는
  전부 이 참조 방식을 쓰므로 통째로 못 쓴다.
- 인라인 SVG 안의 `<style>` 규칙은 **그 SVG가 아니라 문서 전체에 적용된다.** 앱
  UI가 깨진다.
- 반투명/미채색 fill은 뒤의 칩 배경을 비치게 하는데, 그 배경색은 선택 여부에 따라
  바뀐다 → 클릭할 때마다 아이콘 색이 변한다.

**그라디언트가 필요하면** 같은 색 계열 rect를 3~5장 겹쳐 계단으로 만든다. 18px에서는
어차피 그렇게 보이고, 이 프로젝트의 기존 아트 스타일과도 맞는다.

### `<svg>` 태그의 나머지 속성은 자유

`width` / `height` / `shape-rendering` / `xmlns`는 **미리보기 편의용이라 무엇이든
상관없다.** 소비하는 쪽은 `<rect>` 목록만 읽고 래퍼를 다시 씌운다. 아래 예시처럼
`width="384" height="384"`(24의 16배 확대)로 두면 파일을 그냥 열었을 때 크게 보여
작업하기 편하다.

## 3. 완전한 예시 (그대로 복사해서 출발점으로 써도 된다)

아래는 규격을 전부 만족하는 **실제로 검증된** 파일이다 — rect 8개, 594바이트,
576칸 전부 칠해짐, 색 4개. 이것은 **형식 시범용 도형이지 실제 물질이 아니다.**

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="384" height="384" viewBox="0 0 24 24" shape-rendering="crispEdges">
  <rect x="0" y="0" width="24" height="24" fill="#78608e"/>
  <rect x="0" y="0" width="24" height="2" fill="#8f76a6"/>
  <rect x="2" y="2" width="2" height="18" fill="#8f76a6"/>
  <rect x="0" y="20" width="24" height="4" fill="#5b4870"/>
  <rect x="8" y="6" width="8" height="2" fill="#2e2438"/>
  <rect x="8" y="14" width="8" height="2" fill="#2e2438"/>
  <rect x="8" y="8" width="2" height="6" fill="#2e2438"/>
  <rect x="14" y="8" width="2" height="6" fill="#2e2438"/>
</svg>
```

읽는 법:

1. **1번 rect가 타일 전체를 기본색으로 덮는다.** 항상 이렇게 시작한다. 이 한 줄이
   "투명 금지"를 자동으로 만족시켜 준다.
2. 그 위에 밝은 띠(위쪽)와 어두운 띠(아래쪽)를 얹어 입체감을 만든다 —
   **광원은 항상 왼쪽 위**.
3. 마지막으로 형태를 그린다. 여기서는 두께 **2유닛**짜리 사각 고리.
   1유닛은 축소 과정에서 사라질 수 있으므로 쓰지 않는다.

`<rect>`는 **높이가 1일 필요가 없다.** 같은 색 덩어리는 큰 사각형 하나로 묶는 게
좋다 — 파일이 작아지고 읽기도 쉽다.

## 4. 그리기 지침

### 크기 — 이게 제일 중요하다

- 24×24로 그리지만 **표시는 18×18이다.** 0.75배로 줄어든다.
- **최소 특징 두께 2유닛.** 1유닛 선·점은 축소에서 없어질 수 있다. 외곽선도 2유닛.
- 그리는 중간중간 **24×24 이미지를 18×18로 줄여 보고** 형태가 남는지 확인한다.
  남지 않으면 디테일을 줄이고 형태를 키운다.
- 요소는 **3~4개까지**. 18px에 그 이상은 안 들어간다.

### 색

- **지정된 기본색이 타일을 지배해야 한다 — 면적의 60% 이상.** 사용자들은 이미 그
  색으로 물질을 외우고 있다. 못 알아보게 되면 개선이 아니라 개악이다.
- **색은 총 4~5개까지.** 한 면에 명암 3톤 이하.
- 파생색은 기본색에서 밝기만 옮겨 만든다(예: 기본 `#78608e` → 밝음 `#8f76a6`,
  어두움 `#5b4870`). 색상(hue)을 크게 틀지 않는다.
- **순백 `#ffffff` / 순흑 `#000000`을 넓게 쓰지 않는다.** UI가 어두운 톤이라 튄다.
  대신 `#e8e8ee`(밝은 끝) / `#0d0d12`(어두운 끝)를 쓴다.

### 형태

- **광원은 왼쪽 위.** 밝은 면은 위·왼쪽, 그림자는 아래·오른쪽.
- 입체감은 그라디언트가 아니라 **띠·이음매·면 분할**로 낸다.
- **글자·숫자·기호·화살표 문자를 그리지 않는다.** 18px에서 안 읽히고, 이 앱은
  한국어/영어를 전환하므로 글자가 들어가면 번역과 충돌한다.
- **물질 자체를 그린다. 장면을 그리지 않는다.** 불꽃·연기·폭발·반짝임 이펙트는
  그리지 않는다 — 게임 안에서 그건 실제로 시뮬레이션되는 별개의 입자이지 그림이
  아니다. 예: 다이너마이트는 막대만 그리고 도화선 불꽃은 그리지 않는다.
- 타일은 **물질 덩어리를 정면에서 본 표면**이라고 생각하면 대체로 맞다. 개념
  물질(§5-A)만 상징으로 간다.

### 대비 확인용 참조값

아이콘 뒤·주변에 실제로 오는 색이다. 이 위에서 형태가 보이는지 확인한다.

| 위치 | 색 |
|---|---|
| 칩 배경(평소) | `#1b1b22` |
| 칩 배경(선택됨) | `#232b3a` |
| 타일 테두리 | 흰색 15% 불투명, 1px, 모서리 반경 4px |
| 게임 캔버스 바탕 | `#101016` |

## 6. 납품 전 자체 점검

한 파일씩 아래를 전부 확인한다. **하나라도 어긋나면 반려된다.**

- [ ] `viewBox="0 0 24 24"` 이고 XML 선언·DOCTYPE이 없다
- [ ] `<rect>` 외의 도형 요소가 하나도 없다
- [ ] 모든 `x` `y` `width` `height`가 정수, `width`/`height` ≥ 1
- [ ] 모든 `fill`이 `#rrggbb` 6자리 소문자
- [ ] **첫 rect가 `x="0" y="0" width="24" height="24"`** 로 타일 전체를 덮는다
- [ ] `id` / `class` / `<defs>` / `<style>` / `<g>` / `url(` / `gradient` /
      `opacity` / `stroke` / `none` 이 파일 안에 **한 번도** 등장하지 않는다
- [ ] rect 200개 이하, 6 KB 이하
- [ ] 색 5개 이하
- [ ] 지정 기본색 계열이 면적의 60% 이상
- [ ] 가장 얇은 요소가 2유닛 이상
- [ ] **18×18로 줄여 봤을 때** 무엇인지 알아볼 수 있다
- [ ] `#1b1b22` 배경 위에 놓았을 때 형태가 보인다
- [ ] 글자·숫자가 없다

### 기계적으로 확인하고 싶다면

이 스크립트가 규격 위반과 빈 칸을 잡아낸다(Node 필요, 의존성 없음).

```js
// node check.mjs foo.svg
import { readFileSync } from 'node:fs';
const s = readFileSync(process.argv[2], 'utf8');
const bad = /\bid=|\bclass=|<defs|<style|<g[ >]|<use|<image|<text|url\(|gradient|opacity|stroke|fill="none"|<\?xml|<!DOCTYPE/i.exec(s);
if (bad) throw new Error('금지 요소: ' + bad[0]);
if (!/viewBox="0 0 24 24"/.test(s)) throw new Error('viewBox가 0 0 24 24 가 아님');
const cells = new Set();
let rects = 0;
for (const m of s.matchAll(/<rect x="(\d+)" y="(\d+)" width="(\d+)" height="(\d+)" fill="(#[0-9a-f]{6})"\s*\/>/g)) {
  rects++;
  const [x, y, w, h] = [+m[1], +m[2], +m[3], +m[4]];
  if (x + w > 24 || y + h > 24) throw new Error('타일 밖으로 나감: ' + m[0]);
  for (let j = y; j < y + h; j++) for (let i = x; i < x + w; i++) cells.add(j * 24 + i);
}
if (rects !== (s.match(/<rect/g) || []).length) throw new Error('형식에 안 맞는 rect가 있음');
if (cells.size !== 576) throw new Error(`빈 칸 ${576 - cells.size}개 — 배경 rect 누락?`);
if (rects > 200) throw new Error('rect ' + rects + '개 — 200 초과');
if (s.length > 6144) throw new Error(s.length + ' B — 6 KB 초과');
console.log(`OK — rect ${rects}개, ${s.length} B`);
```
