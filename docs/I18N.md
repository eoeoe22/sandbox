# 다국어(i18n) 가이드

이 프로젝트는 한국어(ko)와 영어(en)를 지원하며, 설정 모달에서 언제든 전환할 수 있다.
외부 i18n 라이브러리 없이, 기존 nanostores atom 위에 가벼운 번역 헬퍼를 직접 구현했다.

## 아키텍처

- **코어**: [`src/i18n/index.ts`](../src/i18n/index.ts)
  - `$locale` atom (`'ko' | 'en'`) — 초기값은 브라우저 언어 자동 감지.
  - `t(key, params?)` — 점 표기 키(`'tool.brush.material'`)로 UI 문자열 조회. `{name}` 형태의 자리표시자 치환. 현재 locale → 영어 → 키 자체 순서로 폴백하므로, 빠진 번역이 UI를 빈칸으로 만들지 않는다.
  - `materialName(id, fallback?)` / `objectLabel(kind)` / `categoryLabel(key)` — 안정적 식별자로 물질·객체·카테고리 표시명을 조회.
  - `syncHtmlLang()` — `document.documentElement.lang`을 활성 locale과 동기화(스크린 리더 등).
- **UI 문자열**: [`src/i18n/ui.en.ts`](../src/i18n/ui.en.ts)(진실의 원천)과 [`src/i18n/ui.ko.ts`](../src/i18n/ui.ko.ts)(한국어 번역). 중첩 객체 구조.
- **물질·객체·카테고리명**: [`src/i18n/materials.ts`](../src/i18n/materials.ts). 물질은 숫자 id, 객체는 `ObjectKind`, 카테고리는 안정적 영문 키로 색인.
- **영속화**: [`src/state/persistence.ts`](../src/state/persistence.ts)가 `$locale`을 `settings:v1` 스키마에 저장·복원.
- **첫 페인트 전 감지**: [`src/layouts/Base.astro`](../src/layouts/Base.astro)의 `<head>` 인라인 스크립트가 localStorage와 브라우저 언어로 `<html lang>`을 보정(하이드레이션 전 깜빡임 방지).

## 카테고리 키 규칙

카테고리는 한국어 문자열(`'고체'`, `'폭발'`)이 아니라 **안정적 영문 식별자**(`'solid'`, `'explosive'`)로 표현한다. 이 키는 `Material.category` 필드, `CATEGORY_META`(`src/game/materials/categories.ts`), phase 폴백(`PHASE_FALLBACK`)에서 사용되며, 표시 라벨은 `categoryLabel(key)`이 활성 locale로 반환한다.

전체 키 목록:
`eraser` `solid` `powder` `liquid` `gas` `fire` `smelt` `oil` `explosive` `cooling` `electric` `life` `radioactive` `exotic`

**새 카테고리를 추가할 때**: `CATEGORY_META`에 키+아이콘을 추가하고, `materials.ts`의 양쪽 라벨 테이블(`categoryLabelsEn`/`categoryLabelsKo`)에 표시명을 추가한다.

## 번역 추가/수정 방법

### 새 UI 문자열 추가
1. `src/i18n/ui.en.ts`의 적절한 섹션에 키와 영어 문구를 추가한다(진실의 원천).
2. `src/i18n/ui.ko.ts`의 같은 위치에 한국어 번역을 추가한다.
3. 컴포넌트에서 `t('섹션.키')` (또는 자리표시자가 있으면 `t('섹션.키', { name })`)로 사용한다.

### 새 물질 추가
1. `src/game/materials/`에 물질 파일을 만들고 `register({ id, name: 'English', category: 'stableKey', ... })`로 등록한다.
2. `src/i18n/materials.ts`의 `materialNamesKo`에 `id: '한국어명'`을 추가한다. 영어명은 물질의 `name` 필드에서 자동으로 읽힌다(별도 영어 테이블 불필요).

### 새 객체 종류 추가
1. `src/state/store.ts`의 `ObjectKind`에 종류를 추가한다.
2. `src/i18n/materials.ts`의 `objectLabelsEn`/`objectLabelsKo` 양쪽에 표시명을 추가한다.

## 컴포넌트에서 사용하기

```svelte
<script lang="ts">
  import { $locale as locale, t, materialName } from '../i18n';
  import { getMaterial } from '../game/materials';

  // $locale 변화 시 자동 갱신: void $locale로 의존성을 표시한다.
  const label = $derived.by(() => {
    void $locale;
    const m = getMaterial($selectedMaterial);
    return m ? materialName(m.id, m.name) : '?';
  });
</script>

<span>{t('tool.materialLabel', { name: label })}</span>
```

**목록을 만드는 파생값도 예외가 아니다.** `materialName()`·`t()`는 `$locale.get()`을
평범한 함수 안에서 읽으므로 Svelte의 `$store` 자동 구독에 잡히지 않는다 — 라벨을
마크업에서 부르더라도, 그 마크업을 돌리는 `$derived`(배열이든 문자열이든)가 직접
`void $locale`을 읽어야 언어 전환에 다시 렌더된다. 예컨대 `MaterialPalette`의
빠른접근 슬롯(`quickItems`)은 즐겨찾기·최근 목록만 의존성으로 갖고 있어, 이 표시가
없으면 언어를 바꿔도 별표해 둔 칩의 이름·툴팁만 옛 언어로 남는다.

## 범위 외 (명시적 제외)

- **PWA 매니페스트 다언어화**: `public/manifest.webmanifest`는 단일 언어(한국어 `description`, `lang: ko`)로 유지. 다언어 매니페스트는 빌드 파이프라인 변경이 필요하다.
- **캔버스 내 텍스트**: 렌더러는 `fillText`를 사용하지 않으므로 번역 대상이 아니다.
- **스냅샷 이름**: 사용자 입력이므로 번역하지 않는다.
- **코드 주석**: 한국어/영어 혼합 그대로 유지.
